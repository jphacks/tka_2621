製品概要
1. 背景（製品開発のきっかけ・課題）
「なぜ盛り上がっているのか分からない」という観戦の疎外感
サッカーの試合中、経験者はボールを持っていない選手の動きや守備の連動、スペースを突くパスなどに熱狂しています。
しかし、初心者には「ただボールを蹴り合っているだけ」に見え、周囲の盛り上がりについていけないという課題がありました。

ユーザーが持つ知識を活用した理解支援
人は未知の概念を理解する際、すでに知っている分野の知識と結び付けることで、理解しやすくなります。そこで、ユーザーが詳しいゲームや趣味、日常生活などの身近な題材に専門的な内容を置き換えて伝えることで、初心者でもプレーの意味や面白さを理解し、経験者と一緒に盛り上がれる観戦アシスタントの開発に至りました。

2. 製品説明
Kicklitは、AIによる専門的な解説を、ユーザーが指定した好きなトピックに置き換えて分かりやすく伝えるサービスです。
YouTubeのハイライト動画を入力すると、AIが映像を解析し、プレーの内容や専門家が注目するポイント、そのすごさを解説します。さらに、その解説をユーザーが詳しいゲームや趣味などの知識に置き換え、直感的に理解できる表現へと変換します。
今回のデモでは、サッカーの専門的なプレー解説を「Apex Legends」の知識に置き換えます。サッカーを知らない人でも、自分が詳しいゲームの知識を通じてプレーの意味や面白さを理解できます。
Apex Legendsはあくまで今回のデモで使用する題材であり、特定のゲームに限定されるものではありません。ユーザー一人ひとりが指定した好きなトピックに合わせて解説できることが、Kicklitの特徴です。

3. 特長
① 専門的な内容をユーザーの知識に合わせて翻訳
ゴールやセーブなどの派手な場面だけでなく、相手の守備ラインを崩すパス、おとりの動き、先読みしたパスカットなど、経験者が注目するプレーをAIが抽出します。
さらに、プレーの難しさや構造をユーザーが指定した好きなトピックに置き換えて解説します。単なる言葉の言い換えではなく、プレーの状況や動きの意図を踏まえた説明に加え、実際のサッカーとの違いも示すことで、初心者の直感的な理解を促します。



4. 解決できること
知識がなくても、専門的な内容を直感的に理解できる
専門分野の知識がない人でも、自分が詳しいゲームや趣味などの知識を通じて、「何が起きていて、なぜすごいのか」を理解できます。今回のデモでは、Apex Legendsの知識を手がかりにサッカーのプレーを理解できるようにします。

観戦中の「説明する側・される側」の負担を軽減
経験者が試合中に一つひとつ説明する負担や、初心者が解説文を読むために画面から目を離すストレスを軽減します。友人やカップル、家族など、知識量の異なる人同士でも一緒に観戦を楽しめます。

専門分野への興味を深めるきっかけに
気になった場面はクリックして用語辞書を確認したり、タイムライン上のマーカーから見どころを振り返ったりできます。身近な知識を入り口として、サッカーの戦術や専門用語への理解を深められます。

6. 注力したこと（こだわり・工夫）
① 動画を主役にするUI/UX設計
YouTubeの利用規約に配慮し、プレーヤー上に文字などを重ねず、短いテロップで見どころを伝える設計にしました。またテロップを短くすることで、観戦への集中を妨げずに注意を促します。

② プレーの構造を保った解説生成
単なる言葉の言い換えではなく、「誰がどこにいて、どこにスペースがあり、どのような動きが効果的なのか」という構造を踏まえて、指定された題材に置き換えることにこだわりました。また、実際のサッカーとの違いも明示し、たとえによる誤解を防ぐ設計にしています。
③ API制限への対策とキャッシュ機構
Gemini APIによる動画解析結果やTTS音声を動画IDごとにキャッシュし、同じ動画の再解析や音声の再生成を抑制します。また、通信やAPI利用に問題が発生した場合に備え、サンプルモードやブラウザ音声合成へ切り替える仕組みを実装しました。

8. 独自技術・実装した機能
① マルチモーダル動画解析と自動再生成パイプライン
YouTubeのURLから動画を解析し、見どころ、初心者向け解説、専門的な観点からの解説、指定トピックへのたとえ、用語辞書などを構造化データとして生成する仕組みを構築しました。

② ドメイン特化型品質チェッカー（check.py）
時刻の整合性や文字数に加え、難解な用語や不適切な表現、たとえへの専門用語の混入などを検出します。不合格の場合はAIに修正を促し、品質を改善します。

③ 動画と同期するビューア
動画の再生位置に連動した見どころマーカー、外枠の発光、短いテロップ、実況音声再生時の自動音量調整を実装しました。

④ TTS実況生成・レート制限対策（tts.py）
場面や指定トピックに応じた実況音声を生成し、APIの利用制限エラーを検知した際には、待機時間を段階的に延ばして再試行する仕組みとキャッシュ機構を実装しました。
